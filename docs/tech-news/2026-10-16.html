4. Liquid AI 发布 LFM2.5-24B-A2B：专为本地 agent 打造的开放权重推理模型
📎 Liquid AI 官方博客 / TechRepublic｜2026-10-13（10-15 登上 Hacker News 首页引发讨论）
核心内容
LFM2.5 家族收官之作：24B 参数 MoE，每 token 仅激活约 2.45B 参数，13.1 万 token 上下文，纯推理架构（每次回答先输出思考链）。官方称在 OpenClaw、Pi、OpenCode 等 agent 框架内做了强化学习，在 8 项 agent/工具调用基准中的 5 项上持平或超过参数多 50% 的 Qwen3.6-35B-A3B（官方自报数据）。Base 与后训练版权重均已上架 Hugging Face。
关键影响
"小激活、大总量"正在成为本地 agent 模型的标准答案：每 token 计算成本接近 2B dense 模型，却保留 24B 的知识容量，笔记本即可跑长程 agent 循环。
我的关注点
官方宣称在 Apple M5 Max 上 184 tok/s、单张 B300 上 2.1 万 tok/s——数字很漂亮但都是单方测试。真正有价值的是它"在 agent 框架里做 RL"这条路线：模型不再为聊天榜单优化，而是为工具调用循环优化，这正是本地 agent 最缺的一块拼图。

📎 BFL 官方新闻稿（GlobeNewswire）｜2026-10-15
